# Backend complémentaire Cineva

Ce dossier est réservé aux éléments backend additionnels qui ne vivent pas directement dans Supabase.

Exemples futurs :

- workers de traitement média ;
- scripts d'import catalogue ;
- passerelles notification ;
- services DRM/CDN ;
- utilitaires d'administration ;
- tâches planifiées externes.

## Position actuelle

Pour la première base du projet, la majorité de la logique serveur est prévue dans :

- Postgres / SQL ;
- RLS ;
- Edge Functions Supabase ;
- Storage privé Supabase.
